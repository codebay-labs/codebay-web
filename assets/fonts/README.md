# Fonts

Self-hosted latin subsets, downloaded from Google Fonts:

- **Manrope** — Copyright (c) The Manrope Project Authors, licensed under the SIL Open Font License 1.1.
  https://github.com/sharanda/manrope
- **Instrument Serif** — Copyright (c) The Instrument Serif Project Authors, licensed under the SIL Open Font License 1.1.
  https://github.com/Instrument/instrument-serif
- **JetBrains Mono** — Copyright (c) JetBrains s.r.o., licensed under the SIL Open Font License 1.1.
  https://github.com/JetBrains/JetBrainsMono

Inter is kept for compatibility with older cached stylesheets; the current
stylesheet uses Manrope for Latin body text and falls back to PingFang SC for
Chinese.

The full license text is in `OFL.txt`.
