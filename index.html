常见问题

你可能想问

CodeBay 会上传我的会话或代码吗？

不会。CodeBay 完全离线工作：只读取各 Agent 存在本机的会话文件建立索引，不复制会话内容，没有账号体系，也没有任何遥测上传。

我想用的 Agent 不在内置名单里怎么办？

用「设置 → Agents → Add Agent → 自定义」贴一份 JSON 定义：可执行文件、新会话与恢复参数、会话目录与结构，实测通过即接入。模板占位符覆盖 {project}、{id}、{home} 等，甚至支持 SQLite 型会话存储。

Agent 的 CLI 更新了，会话会不会找不到？

每个 Agent 的可执行文件路径、会话目录与参数都可在设置面板单独覆盖，优先级高于内置默认值，上游改动可以立刻修正。

多个 Agent 同时改一个仓库，会不会互相冲突？

CodeBay 用 Git 工作树隔离：一个分支一份独立 checkout，各跑各的；多个仓库还可组成「工作树组」一起切换。恢复会话时，会话所在的工作树一并就位。

对系统有什么要求？

macOS 14 或更新。CodeBay 本身不代理任何模型请求，你使用的 Agent CLI 需自行安装并配置好登录。
