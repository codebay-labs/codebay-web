ATTENTION, NOT POLLING

Agent 找人，
不是人找 Agent

每个终端 Agent 都会把状态写进标题。CodeBay 读标题判断谁在等你——不装 hook、不改 shell、不接你的 Agent。

  • 琥珀标签等你回应的会话，标签变琥珀；去看了就清除
  • 提示音系统 Glass 音，短促、不重复
  • Dock 弹跳最不容易错过的一个
  • 通知中心点一下直接回到对应会话，跨项目、跨窗口
  • Dock 徽标只统计你还没看到的会话数

阈值默认 8 秒，可调 3–60 秒；纯 shell 永远不会被提醒。已经看见的会话不再打扰。

CodeBay 启动时会用登录 shell 探测一次真实的 PATH，再叠加 Homebrew、npm 全局与常见安装目录兜底，从 Finder 启动也能找到；解析不到时会给出带解决方法的错误，而不是静默失败。

不会。Git 能力止于 commit：没有 push、pull、merge、rebase、PR 或冲突解决编辑器；暂存是文件级，diff 只读，预览只读。push、PR 与合并仍在你的终端里完成。
